# SMITE KNIGHT — Ashen Siege

Оригинальная браузерная castle-siege action game на Three.js. Пройдите пять сюжетных осад или выберите один из двух масштабных режимов войны цитаделей.

В классическом режиме две армии автоматически выходят навстречу друг другу по шести независимым тропам. На карте «Битва на равнине» дорог нет: бойцы свободно перемещаются по всей ширине поля, выбирают ближайшие цели и образуют живую линию фронта в центре. В отрядах чередуются воины, лучники и тяжёлые бойцы; цель — вместе со своей армией разрушить вражеский замок и сохранить союзную цитадель.

В каждом матче действует отдельная экономика: игрок получает золото за время и личные убийства, покупает обычные компоненты и собирает из них уникальные предметы в шестислотовом инвентаре. Предметы усиливают урон, здоровье, защиту, скорость, регенерацию и вампиризм; лечебные зелья восстанавливают здоровье мгновенно.

## Запуск

```powershell
npm install
npm run dev
```

Клиент: `http://127.0.0.1:5173`, игровой сервер: `http://127.0.0.1:3018`.

## Проверка

```powershell
npm run check
npm test
npm run build
npm start
```

## Управление

- `WASD` — движение
- мышь — камера
- `ЛКМ` — удар; удерживать для серии атак
- `ПКМ` — блок
- `Space` — перекат
- `Shift` — бег
- `C` — сменить плечо камеры
- `B` — открыть или закрыть магазин
- `H` — использовать лечебное зелье
- `Enter` — чат в сетевой комнате
- `Esc` — пауза

На телефоне и планшете доступны отдельные экранные элементы: левый стик отвечает за движение, свайп по правой части экрана — за камеру, а удар, щит и бег можно удерживать. Рядом расположены рывок, действие у цели, смена плеча камеры, магазин и лечебное зелье.

Персонажи используют локально поставляемые KayKit GLB, а тематические декорации сюжетных уровней — локально
сгенерированные и оптимизированные GLB из `public/assets/generated/`. Во время игры внешние CDN не нужны.
Источники и лицензия персонажей описаны в `THIRD_PARTY_ASSETS.md`, а воспроизводимые промпты и параметры
декораций — в `GENERATED_ASSETS.md`.

## Production

Production-домен: `https://smite.xedoc.ru`. Node.js слушает только `127.0.0.1:3018`; внешний HTTPS и WebSocket upgrade обслуживает Nginx. Конфигурации находятся в `deploy/`.
